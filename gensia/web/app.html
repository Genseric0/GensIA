Começa pelo token apresentado no terminal.

No computador onde a GensIA corre, confirma o nome de um modelo já instalado:

ollama list

Para ativar a conversa, termina a execução atual da GensIA e inicia-a com esse nome no lugar de NOME_LOCAL:

python -m gensia.api --chat-model NOME_LOCAL --ephemeral-token

Configura OLLAMA_NO_CLOUD=1 no servidor Ollama e reinicia-o antes de usar dados sensíveis. A verificação depende de um daemon confiável. Os comandos são instruções para execução manual.
